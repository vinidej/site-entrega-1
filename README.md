# Flamengo 2019.
A tarefa é fazer duas páginas html linkadas e utilizando CSS.
Eu irei fazer um site que apresente o lendário time do Flamengo de 2019.
Como referência eu pedi pra IA criar a tela, e a partir dela eu me baseei para criar o site. 
O prompt foi: 
> "Crie a tela de um site que apresente o lendário time de 2019 do Flamengo. Seja simples, a ideia é usar apenas HTML e CSS, sem JavaScript. Não apresente código; quero apenas a tela para fazer o código baseado nela."

## Conteúdo do site

O projeto possui duas páginas:

- **Página inicial (`index.html`):** apresenta a temporada de 2019, as principais conquistas, o treinador Jorge Jesus e alguns dos jogadores que marcaram aquele elenco.
- **Página de estatísticas (`ironia.html`):** exibe, de maneira totalmente profissional, estatísticas dos jogadores destacados na página principal.

As páginas possuem links que permitem navegar entre elas.
Veja o final para entender melhor sobre a página 'ironia.html'.
